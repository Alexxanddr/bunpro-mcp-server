# Security policy

## Supported versions

The package is not published yet. After publication, security fixes will target the latest supported release line documented here.

## Reporting a vulnerability

Do not open a public issue for a vulnerability or include a Bunpro bearer token, account response, or other personal data in a report.

No private reporting channel has been designated yet. Before making this repository public, the maintainer must configure GitHub private vulnerability reporting or publish a dedicated security contact here. Until then, avoid public disclosure and contact the maintainer through an already established private channel.

Include the affected version, impact, reproduction steps, and a minimal sanitized proof of concept. The maintainer should acknowledge the report, assess scope, prepare a fix and advisory, and coordinate disclosure. No response-time guarantee is currently offered.

For the implementation's trust boundaries and known risks, see [docs/SECURITY.md](docs/SECURITY.md).
