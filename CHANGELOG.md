# Changelog

All notable changes will be documented here. The project follows [Semantic Versioning](https://semver.org/) once releases are published.

## [Unreleased]

## [0.3.0] - 2026-10-22

- Added `get_weak_items` to rank both grammar and vocabulary using study count and historical accuracy.

## [0.2.4] - 2026-10-22

- Aligned npm, MCP Registry, and runtime version metadata for automated publishing.

## [0.2.2] - 2026-10-21

- Added npm publication metadata and complete package documentation.
- Added tokenless npm publishing from GitHub Releases through Trusted Publishing.
- Added automated publication metadata for the official MCP Registry.
- Updated the supported runtime to maintained Node.js 22 and 24 releases.
- Added open-source project documentation, agent instructions, reusable MCP workflows, CI, and release validation commands.

## [0.1.0]

- Initial read-only MCP tools for Bunpro profile, reviews, study statistics, vocabulary, decks, topics, and search.
